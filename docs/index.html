Four views, one object?

A LoRA on FLUX.1-dev was trained to draw a 2×2 grid showing one object from four sides. The question: does it keep the object the same across the tiles without cheating by drawing the same view four times? Every generated grid from the study is here, with its scores.

Verdict under the pre-registered rule: pending · protocol

Why: with prompt and seed fixed, the LoRA moves each tile about an eighth as far as a new seed does, and it never learned the black side bars every training photo had. The three training runs do push each picture the same way. The effect is real, just small.

Identity against view diversity

Identity alone is a trap: four copies of one view score perfectly. So every grid is a point on two axes. Each line joins one prompt's base-model average to its LoRA average. Further up is a more consistent object; further right is more distinct viewpoints. Click a point to open that prompt below.
